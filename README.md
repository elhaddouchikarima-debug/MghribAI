# 🇲🇦 MghribAI — Discover Morocco. Your Way.

MghribAI is an AI-powered tourism project designed to help travelers explore Morocco and discover personalized travel experiences based on their interests and budget.

### ✨ Features
- Explore Moroccan destinations.
- Discover local activities and experiences.
- Plan personalized trips.
- Discover Moroccan food and accommodation.
- AI-assisted tourism recommendations.

### 🛠️ Technologies
- HTML, CSS, JavaScript
- Node.js
- Apertus AI

### 🏆 Hackathon
Developed for **HackApertus 2026 — Track 2B**.
